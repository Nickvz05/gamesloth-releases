# GameSloth Server v0.34.0 — Founding 50

## What it does

The first 50 GameSloth squad hosts who successfully finish an online Sloth Sync Moment with at least two ready POVs receive Sloth+ for two calendar years.

A failed Moment does not claim a spot. A host can claim only once. The global claim order is protected by a PostgreSQL advisory lock so two Moments completing at the same time cannot both receive the same position.

## Why the reward is separate from creator access

Founding 50 data lives on dedicated user fields instead of reusing `alpha_plan_override`. This means:

- an existing Sloth Pro creator grant is never replaced by Sloth+;
- a paid subscription can stay active normally;
- if paid access ends while the two-year Founding reward is still active, Sloth+ remains available;
- creator grants can still be edited or revoked independently.

## Qualification

A reward is checked only after the host reports a completed `ready` or `partial` Sloth Sync Moment. At least two distinct connected users must have a `ready` POV in the Moment status.

The squad owner / host receives the reward because the host plan controls the squad's Moment limits.

## Alpha Admin

`/alpha/admin` now contains a **Founding 50** page with:

- claimed / remaining spots;
- active, paused or complete status;
- a pause/resume control;
- claim order, player, date, POV count and Sloth+ expiry;
- Founding 50 information inside player details.

Pausing never removes an existing reward.

## Client/API

`GET /api/entitlements` adds:

```json
{
  "founding50": {
    "winner": true,
    "position": 7,
    "claimedAt": 0,
    "expiresAt": 0,
    "active": true
  }
}
```

When a reward is first earned, the host WebSocket receives:

```json
{
  "type": "founding_50_awarded",
  "position": 7,
  "plan": "SLOTH_PLUS",
  "expiresAt": 0,
  "message": "You’re Founding 50 #7. Sloth+ is unlocked for 2 years."
}
```

Older clients can safely ignore the extra WebSocket message.
